# 覇業 HEGEMONY ― 三国逐鹿戦略

単一 HTML ファイルで動く、三国時代（西暦194年）を舞台にしたターン制戦略＋戦術ゲーム。
`index.html` をダブルクリックするだけで起動します（ビルド不要・サーバー不要）。

- 原型: `../WarringStatesRuler/index.html`（春秋戦国戦略）。**元作は変更していません。**
- 本作: 舞台を三国時代へ移し、戦闘演出・内政と外交の深さ・AI・UI/操作性を全面刷新。
- 言語: 日本語 / English / 中文（タイトル画面または上部のセレクトで即時切替・保存される）

---

## 1. 遊び方（30秒）

1. `index.html` を開く（Chrome / Edge / Firefox 推奨、要インターネット接続でライブラリを読み込む）
2. タイトルで**勢力**と**難易度**を選んで「旗を挙げる」
3. 季節（春→夏→秋→冬）ごとに政令を振り分け、都市を発展させ、兵を動かし、他勢力と交渉する
4. 出兵すると盤面に移る。**兵科の相克**と**地形・天候・戦法**で数を越える
5. すべての都市を制圧すれば**天下一統**、自国の全都市を失えば**敗北**

> 音は最初のクリック／タップから始まります（ブラウザの自動再生ポリシーのため）。
> 接続が無い・CDNが止まった場合は、自作のcanvas2D地図・DOM盤面・WebAudio合成に自動で落ちます。

## 2. 元作からの主な改善

| 分野 | 改善内容 |
|---|---|
| 時代設定 | 春秋戦国 → **三国時代（西暦194年・漢興平元年）**。10勢力・30都市・街道40本・在野武将8名 |
| 戦闘演出 | PixiJS による盤面描画＋GSAP の移動／被弾／破壊シェイク、戦法発動の閃き、Damage 数字の吹出（未取得時は DOM 盤面にフォールバック） |
| 戦闘の読みやすさ | 移動可能マスのハイライト、攻撃対象の縁取り、兵科アイコン、守り手側は**盤面を上下反転**、本営HP／士気／戦術ポイントの常時表示 |
| 天候 | 晴朗／降雨／干旱／雾／雪害／酷暑。火計の効き、射程、移動、川が浅瀬になる（干旱）等が変化 |
| 地形 | 街道種別（平原／丘陵／山地／河）と盤面地形（森林が燃えて焦土化する、村落・浅瀬・城門・城壁） |
| 兵科相克 | 騎>歩>弩>槍>騎 の循環。編成（10単位の割り振り）を都市ごとに整編できる |
| 戦法 | 武将の智略で発動。**火計／突撃／鼓舞／奇襲／離間／一斉射**（戦術ポイント制） |
| 特産 | 米・塩・馬・鉄・絹。都市ごとに収入と兵科の質へ反映 |
| 内政 | 墾荒・市集・修城・練兵・征兵・安抚に、**动荡**（民心が低いと徴税と徴兵が痩せる）を追加 |
| 外交 | 使节（講和）／同盟／宣戦／離間。**休戦期間**と関係値、AI同士の外交も回る |
| 諜報 | **斥候**と**離間**。未観測の都市は兵力・城墙が `?` 表示（4季節前で陳腐化）、隣接都市のみ自動観測 |
| 武将 | 53名。統率・武力・智略に加え**忠節**があり、 unpaid や敗戦で**出奔**する。在野武将の訪訪（登用は1季節1名）、捕虜の処置（登用/放出/処刑） |
| 将の因縁 | 特定の武将の組み合わせに **恩怨** 補正（与えるダメージ増／被ダメ増） |
| 戦闘の深み | 包囲（隣接する味方1人ごとに与ダメ+8%）、**歴戦**（経験値で兵が強化）、本営攻略で即決着、24ターン経過で決着付き、**自動決着**ボタン |
| 国力比較 | Chart.js による**国力グラフ**（都市／金／兵糧／兵／威望の推移、未取得時は canvas2D 自作描画） |
| AI | 焦点の設定（攻め先を維持）、兵力比での攻撃判断、内政の優先順位、開戦・講和・同盟の判断、序盤6季節は攻撃手控え（難易度で変化） |
| UI | 縦画面（スマホ）対応、ヘルプ Overlay、事件通知のまとめ表示、**助言**パネル、キーボードショートカット |
| 継続 | localStorage へ自動セーブ（起動時に続きから再開）、戦績プロファイル（言語・音量・勝利回数） |

## 3. 操作

### マウス／タッチ
- 地図の都市をクリック → 右パネルで内政・出兵・武将
- 隣接する他国都市を選択 → 「出兵」→ 兵力スライダー → 進軍
- 戦闘盤面：自兵をクリック → 移動先／攻撃先をクリック（本営も攻撃できる）
- 「自動結着」で戦闘を即決着、「撤退」で本隊を帰還

### キーボード
| キー | 動作 |
|---|---|
| `N` | 季節を終える |
| `G` | 国力グラフを開く |
| `S` | 手動保存 |
| `矢印` | 隣接する都市を選ぶ（国政画面） |
| `Enter` | 選んだ都市を開く |
| `Space` | 戦闘のターンを終える |
| `U` | 戦闘一手を撤销 |
| `F` | 戦法（自武将の戦法を発動／狙いを外す） |
| `R` | 戦闘で撤退 |
| `A` | 戦闘を自動決着 |
| `H` / `?` | ヘルプを開閉 |
| `Esc` | 狙い・Overlay を解除 |

## 4. 難易度

| 難易度 | 内容 |
|---|---|
| 簡単 | AI は慎重・収入優遇。序盤は攻められにくい |
| 普通 | AI は兵力比を見て攻める。講和も結ぶ |
| 困難 | AI が積極的（攻撃基準が低く、収入も良好）。他国が早く併合される |

60季節（15年）の自動対戦では、**1〜3勢力が滅びる**ペースで地図が動きます。
無対策で置くと滅ぶ設計です（無為な玩家は11〜41季節で破滅）。

## 5. 使用ライブラリ（CDN・固定バージョン）

| 用途 | ライブラリ | 読み込み先 | 未達時のフォールバック |
|---|---|---|---|
| 盤面描画 | PixiJS 8.6.6 | `cdn.jsdelivr.net/npm/pixi.js@8.6.6/dist/pixi.min.js` | DOM＋CSS の盤面 |
| 演出 | GSAP 3.12.5 | `cdn.jsdelivr.net/npm/gsap@3.12.5/dist/gsap.min.js` | CSS トランジション |
| 音 | Tone.js 14.8.49 | `cdn.jsdelivr.net/npm/tone@14.8.49/build/Tone.js` | WebAudio 直叩き合成 |
| グラフ | Chart.js 4.4.3 | `cdn.jsdelivr.net/npm/chart.js@4.4.3/dist/chart.umd.js` | canvas2D 自作グラフ |
| 文字 | DotGothic16 / Ma Shan Zheng | Google Fonts | システムフォント |

- `file://` で開けるよう **ES Modules は不使用**（classic script のみ）。
- 各スクリプトの `onload/onerror` で成否を記録し、機能ごとに代替へ切り替わります。
- 実行中の外部通信はライブラリとフォントの読み込みだけで、**ゲームデータの取得は行いません**。

## 6. ファイル構成

```
Hegemony/
├── index.html       … ゲーム本体（この1ファイルで完結）
├── README.md        … 本書
├── i18n_zh.js       … 中文翻訳のソース（index.html 末尾に埋め込み済み・352キー）
└── tests/
    ├── run-all.js        … 全テスト一括（node tests/run-all.js）
    ├── dom-contract.js   … HTML と JS の参照噛み合い・多言語キー整合
    ├── headless-test.js  … エンジン不変条件（季節進行・戦闘・外交・諜報等）
    ├── stub-dom.js       … スタブDOMで UI 一式を実際に走らせる
    └── balance.js        … 戦闘バランスと AI の攻城ペースの実測
```

### テストの走らせ方（Node.js があれば十分／依存パッケージ無し）

```
node tests/run-all.js          # 3スイート一括
node tests/headless-test.js 48 # 季節数を指定
node tests/balance.js 160      # 戦闘バランス実測
```

直近の実測:
- DOM契約 **991件 成功**（id・多言語キー・画面／Overlay・CDN URL・ESM非使用の確認）
- エンジン不変条件 **約1.9万〜2.0万件 成功**（資源が有限／領有都市の生存／士気とHPの範囲／losses ≤ 出兵数 等）
- スタブDOM実操作 **無エラー**（起動→言語切替→内政→外交→出兵→戦闘→グラフ→保存→再開）
- 戦闘 90戦で **攻撃側勝率 48〜54%**（決着: 本営攻略・全滅・時間切れ）、兵力0.8倍未満なら攻33〜48%／1.0〜1.25倍で64〜80%

## 8. 日本語・英語・中文の三言語表記（要約）

**日本語** ― 漢が衰え、群雄が逐鹿する。194年、あなたは10勢力の一つを担ぎ、都市を発展させ、
武将を登用し、外交と諜報を巡らせ、戦場で兵科の相克と天候・地形を読む。目标是天下一統。

**English** ― A Three Kingdoms grand-strategy game in one HTML file. Pick one of ten warlords in 194 AD,
develop cities, hire wanderers, work diplomacy and espionage, then win battles with counters, terrain and weather.
Unify the realm before your last city falls. Turn-based seasons on the strategic layer, turn-based grids in the field.

**简体中文** ― 单文件 HTML 的三国战略游戏。公元194年，在十大诸侯中选择其一：经营城池、招募在野武将、
出使与离间、派遣斥候，再在战场上以兵种相克、地形与天候以少胜多。战略层为季节回合，战斗层为格子回合。
天下归一即胜，本邦城邑尽失则败。
